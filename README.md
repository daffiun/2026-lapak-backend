# Laporan Peminjaman Kelas - LAPAK - Backend Api

Backend untuk Aplikasi LAPAK (Laporan Peminjaman Kelas) yang digunakan untuk mengelola data peminjaman kelas di lingkungan sekolah. Aplikasi ini memungkinkan pengguna untuk membuat, membaca, memperbarui, dan menghapus laporan peminjaman kelas dengan mudah.
